# TP2 — Artificial Intelligence

## Overview

This repository contains the work developed for the second practical assignment (TP2) of the **Artificial Intelligence** course at **Grenoble INP – Esisar**.

The assignment focuses on applying artificial intelligence and machine learning concepts to a practical problem.

## Project — Automatic Candy Selector (ACS)

The project aims to develop an automatic candy selection system using computer vision and deep learning techniques.

The main tasks include:
- Image classification.
- Object detection.
- Model training and evaluation.
- Performance analysis and comparison.
